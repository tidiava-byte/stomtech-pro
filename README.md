# STOMTECH PRO — сайт

Многостраничный статический сайт STOMTECH PRO — профессиональные порошки для воздушно-абразивной чистки зубов.

- Чистый HTML/CSS/JS без зависимостей и сборки
- Адаптивный (mobile-first), самодостаточный (шрифт Onest и логотип — локально)
- SEO-структура: продуктовые страницы, совместимость, блог, микроразметка

## Локальный просмотр

Откройте `index.html` в браузере или запустите любой статический сервер в этой папке.

## Публикация

Развёрнут через **GitHub Pages** (ветка `main`, корень репозитория).
