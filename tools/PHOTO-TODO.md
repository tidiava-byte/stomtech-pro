# Нужные фотографии для статей

**Сейчас недостающих кадров нет** — все статьи с фотографиями, заглушек в сборке не осталось
(проверено 2026-08-11).

Файл ведёт сборка. Как только в статье появится место под фотографию, которой нет
в `site/assets/img/blog/`, `node tools/build.mjs` перезапишет этот файл списком недостающих
кадров с описанием сюжета.

Порядок работы:

1. Взять сюжет из списка, который сформирует сборка.
2. Сгенерировать кадр по правилам `PHOTO-DIRECTION.md` и промптам `PHOTO-PROMPTS-2.md`.
3. Положить файл в `site/assets/img/blog/` под точным именем из списка.
   Формат: WebP, ширина 1200–1600 px, соотношение 16:9.
4. `cd site && node tools/build.mjs` — заглушка в статье заменится сама, обложка карточки
   в блоге подтянется автоматически.
